## Asserts (tests/reprice.rs)

1. `plan_reprice(false, …)` → preview JSON: `transmits: false`, current limit, `new_price`,
   notional. No `Submit` arm. Over-cap preview sets `risk_blocked: true` and still does not submit.
   OPT notional uses multiplier 100.
2. `plan_reprice(true, paper, …)` → `Submit` whose `order_id` equals the open order.
   `reprice_order` keeps that id, qty, action, tif; sets the new limit and `transmit`.
3. `plan_reprice(true, live, cap, …)` over cap → `code=guard`, exit 64, message contains
   "exceeds cap". Paper over the same cap still submits.
4. `submit_timeout_error` → `code=unconfirmed`, exit 8, message contains `UNCONFIRMED` and
   `Do NOT retry`. Transport-after-send is the same exit. Rejection notice 201 → exit 7.
   Code 202 is not a rejection. Local `InvalidArgument` before send → exit 4.
   Non-LMT and BAG → exit 4, nothing sent.
5. CLI: bad price and missing args → usage/64. Invalid `OMI_MAX_NOTIONAL` → guard/64 before
   connect. `--confirm --live` without `OMI_ALLOW_LIVE` → config/5.
