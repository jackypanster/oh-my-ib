## Assumptions

- |Δ|-nearest tie detection in `select_pcs` compares distances with the 1e-6 float tolerance (`approx_eq`)
  before the lower-strike tiebreak — the frozen tie case (|Δ| 0.25 vs 0.15 around 0.20) is mathematically
  equal but differs by ~1e-17 in f64.
- A failed stock snapshot in the spot pass is treated exactly like `pick_spot → None`: `spot_unavailable`
  (not `quote_error`).
- A symbol with zero pass-1 contracts (no listed strike in [0.65×spot, spot]) is `quote_error` — the "every
  pass-1 contract failed" rule applied vacuously.
- `refine_strikes`' `already` set is the REQUESTED coarse strikes (not the successfully fetched rows), so a
  failed coarse snapshot is not retried in pass 2.
- `snapshot_batch` sleeps 20ms between subscribes inside a chunk (arch-sanctioned ≤20ms pacing guard for IB
  error 100).
- The chain step keeps SMART rows only; the "most expirations" fallback tie-breaks by lexicographically
  greatest `trading_class`.
- Duplicate symbols in argv are not deduplicated: each input element appears exactly once across
  `candidates` ∪ `skipped`.

## Required fix (review-01)
